# J: UI (User Interface)

Masahiro Sakurai's knowledge on user interface, accessibility, and intuitive design.

## J: UI1 (#01～#08)
[YouTube Video Link](https://www.youtube.com/watch?v=33njSckMINk)

### 推奨される「ルール」・「ゲーム設計思想」
- **右脳的処理の優先:** 文字を読ませる前に「色」や「絵」で直感的に判断させる（例：メニューごとの色分け）。
- **文字サイズの配慮:** 携帯モードでのプレイを前提とし、文字サイズは基本「大きめ」に設定する。
- **アクセシビリティ:** HUDサイズの変更、スティックの入れ替え、色彩調整など、多様なユーザーへの配慮を盛り込む。

### 具体的な数値（仕様・実績）
- **アイコンの強弱:** 決定ボタンやよく使うメニューは物理的に大きく表示し、視線を誘導する。

### 「NG（非推奨）」とされる例
- **文字主体のUI:** 説明を読まなければ理解できないUIは、ゲームのテンポを著しく損なう。
- **酔い対策の不在:** 激しい画面の動きがある場合、中央にドットを表示するなどの対策を怠らない。
