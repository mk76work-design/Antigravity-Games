# Antigravity Games

Google Antigravity エージェントによって開発された、高品質なウェブゲームのコレクションです。

## 収録ゲーム

### 🎮 Emoji Climber (絵文字クライマー)
『Getting Over It』や『Jump King』にインスパイアされた、ゲキムズ物理アクションゲーム。
- **特徴**: 慣性の効いた独特な物理挙動、タメジャンプ、感情豊かな絵文字キャラクター。
- **操作方法**: 
  - `←` `→`: 移動
  - `Space` 長押し: ジャンプのタメ
  - `Space` 離す: ジャンプ（方向キーと組み合わせて斜めジャンプ）

## ツール

### 🖌️ Pixel Animator
AIエージェントがドット絵・ドット絵アニメーションの作成を一気通貫で行うためのツール。
**主役はAIエージェントで、人間はCLIが出した結果を軽く確認・手直しするだけ**という
設計思想。目指す品質水準は**スーパーファミコン（16bit）レベルのキャラクター
スプライト・アニメーション**。
- **CLI（推奨・AIエージェント向け）**: `node cli.js generate --prompt "..." --out ...`
  1回で、生成→機械的品質チェック→画像による自己批評→自己修正までブラウザなしで完結し、
  完成したPNG/GIF/JSONをディスクに書き出す。stdoutは機械可読なJSON、進行状況はstderr。
  デフォルトは16px・16色パレットで、小さく速く回すことを優先している。
  SNES水準の密度を狙う場合は `--width 32` 以上を指定できるが、生成・修正が大幅に
  重くなる（後述の速度上の注意を参照）。
- **`node cli.js character`**: 同一キャラクターの複数アクション（idle/walk/attack等）を
  配色・プロポーションの一貫性を保ったまま生成する。基準ポーズを先に確定させ、
  各アクションの生成にその基準デザインを見せることで一貫性を担保しつつ、
  `--concurrency`（デフォルト2）件まで並列生成して待ち時間を短縮する。
- **自己チェック・自動修正**: 生成→機械的な品質チェック→AIによる画像の自己批評
  （「本物のドット絵スプライトに見えるか」（`pixelArtAuthenticity`）と
  「スーパーファミコン水準のシェーディングになっているか」（`shadingQuality`）の
  2軸を最優先項目として明示的にゲート）→（問題があれば）直前の実ピクセルデータを
  見せての修正、を最大2回まで自律的に繰り返す。「完璧な自動承認」までは追い求めず、
  `needs_review`のまま終わった場合は人間/エージェントの軽い手直しに委ねる設計。
  修正が特定の数フレームだけに絞れる場合は、そのフレームだけを送受信する軽量な
  部分修正を使い、全フレーム再送信のコストを避ける。
- **速度について（正直な注意点）**: 実測では16px・6フレームの生成が自己チェック
  込みで15〜20分程度かかる。ボトルネックはピクセルデータのペイロードサイズより、
  `claude` CLI呼び出し1回あたりの固定コスト（起動・認証・モデルの応答待ち）が
  支配的で、待たせる前提で使うツールだと理解しておくこと（詳細は
  `docs/LESSONS_LEARNED.md`の2026-08-29エントリを参照）。
- **ブラウザUI（人間の手直し用）**: `npm run dev` で起動。CLIが出したJSONを読み込んで
  ペンシル/消しゴム/スポイト/バケツで軽く手直しし、再書き出しできる。
- **APIキー不要**: Anthropic APIは使わない。ローカルにインストールした
  Claude Code CLI（`claude`コマンド）を裏で呼び出し、`claude login` 済みの
  Claude Pro/Max/Teamサブスクリプションの認証でそのまま動く。事前に
  ターミナルで `claude login` を済ませておくこと。

## 開発環境のセットアップ

各プロジェクトのディレクトリに移動し、Vite を使用して起動します。

```bash
cd EmojiClimber
npm install
npm run dev
```

```bash
cd PixelAnimator
npm install

# AIエージェント向け: ブラウザ不要でCLIから直接生成（デフォルトは16px・小さく速く）
node cli.js generate --prompt "剣を構えた侍の待機モーション" --frames 8 --out ./output/samurai_idle

# 人間の手直し用: ブラウザUI
npm run dev
```
