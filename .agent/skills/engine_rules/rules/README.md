# ルールファイル管理ガイド

このディレクトリには、ゲームエンジン / フレームワーク固有の開発ルールをMarkdownファイルとして配置する。

---

## ルールファイルの追加方法

### 1. 新しいファイルを作成
```
rules/
└── [技術名]_rules.md
```

### 2. 以下のフォーマットに従って記述

```markdown
# [技術名] ルール

## バージョン情報
- 対象バージョン: X.Y.Z
- 最終更新: YYYY-MM-DD

## 推奨パターン
（コード例付きで推奨パターンを記述）

## 禁止パターン
（コード例付きで禁止パターンとその理由を記述）

## CDN / インポート
（正しいインポート方法とバージョン固定のURL）

## パフォーマンスガイドライン
（技術固有のパフォーマンス改善策）
```

## いつ更新するか

- **ライブラリ更新時**: CDN URLとバージョン番号を更新
- **ハルシネーション発生時**: 問題のあるパターンを禁止リストに追加
- **新しいベストプラクティス発見時**: 推奨パターンに追加
