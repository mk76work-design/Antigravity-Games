### ファイル構成
```
game-name/
├── index.html      # エントリポイント
├── style.css       # スタイル
├── js/
│   ├── main.js     # ゲームループ・初期化
│   ├── player.js   # プレイヤーロジック
│   ├── enemy.js    # 敵ロジック
│   ├── ui.js       # UI / HUD
│   └── utils.js    # ユーティリティ
└── assets/
    ├── images/     # 画像アセット
    └── sounds/     # 音声アセット
```

### 主要クラス / モジュール
| クラス名 | 責務 |
|----------|------|
| `Game` | ゲームループ、状態管理 |
| `Player` | プレイヤーの入力処理・描画 |
| `Enemy` | 敵のAI・動作 |
| `UI` | スコア表示・メニュー |
