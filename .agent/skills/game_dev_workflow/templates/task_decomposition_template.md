# 🧩 並列タスク分解テンプレート

> Manager Surface から複数のエージェントに並列委譲するためにタスクを分解する。
> 各タスクは**独立して実行可能**であること。

---

## マルチエージェント役割モデル

本テンプレートでは、ACE（Agentic Context Engineering）フレームワークに基づく4役割を使用する。

| 役割 | アイコン | 責務 |
|------|---------|------|
| **Planner** | 📋 | 要件定義、アーキテクチャ設計、タスク分解 |
| **Coder** | 💻 | 仕様に基づくコンポーネント実装 |
| **Reviewer** | 🔍 | コード品質・パフォーマンス・セキュリティ検証 |
| **Curator** | 📝 | 教訓の抽出、構造ファイルの差分更新 |

## 並列実行グループ

### グループ A: 設計（逐次）
- [T0] 📋 仕様書・アーキテクチャ設計 → ユーザー承認

### グループ B: 実装（同時実行可能）
- [T1] 💻 ゲームエンジン・コアループ
- [T2] 💻 プレイヤー操作
- [T3] 💻 敵AI設計
- [T4] 💻 UI/HUD構築

### グループ C: 拡張（グループB完了後、同時実行可能）
- [T5] 💻 レベルデザイン
- [T6] 💻 サウンド統合

### グループ D: 検証と記録（最後に逐次実行）
- [T7] 🔍 統合テスト・QA・セキュリティ
- [T8] 📝 ドキュメント・教訓更新
