# Emoji Climber — 教訓ログ

> 開発中の教訓・ハマりポイント・設計判断の記録

### 2026-02-23 初期実装

- **設計判断**: Kaboom.js ではなく Vanilla Canvas 2D を選択
  - **理由**: Kaboom.js がメンテナンス終了。物理演算を完全手動制御し「理不尽チューニング」を容易にするため。
  - **教訓**: 外部ライブラリの依存前にメンテナンス状態を確認すべき

- **設計判断**: 先行入力バッファ（6F）とコヨーテタイム（4F）を初期実装に含めた
  - **理由**: 桜井政博氏のゲームフィール知見に基づき、「激ムズだがフェア」を支える隠し救済として不可欠
  - **教訓**: これらは目に見えないが、ないと理不尽"感"が「本当の理不尽」になる

### 🔄 引き継ぎ事項 (2026-02-23)
> 物理パラメータのチューニングが今後の課題。特に斜面のドリフト力と崩壊足場のタイミングは実際にプレイして調整が必要。
